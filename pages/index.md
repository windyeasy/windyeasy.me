# Windyeasy

Windyeasy个人网站，这是一个前端工程师写笔记博客和胡思乱想随笔的地方。

作为平时爱胡思乱想的人，有时也会将胡思乱想的内容写下并放在网站上来作为一个记录。

有时会写些学习笔记，记录一些自己所了解的东西或对新事物或科技的思考与看法。

如果有什么问题想与我探讨可在这里发[issues](https://github.com/windyeasy/windyeasy.github.io/issues)。

网站的源代码地址: [https://github.com/windyeasy/windyeasy.me](https://github.com/windyeasy/windyeasy.me)
